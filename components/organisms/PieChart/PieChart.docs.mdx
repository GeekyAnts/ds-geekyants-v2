## Accessibility

- The SVG chart has `role="img"` with a descriptive `aria-label` including the chart title
- A visually hidden `<table>` provides a full data fallback for screen readers, with columns for segment name, value, and percentage share
- The hidden table includes `<caption>`, `<thead>`, `<tbody>`, and `<tfoot>` for proper table semantics
- The info icon button has both `aria-label` and `title` attributes
- The period selector has an `aria-label` for screen reader context
- The tooltip uses `role="tooltip"` with `pointer-events-none`
- Colour legend swatches use `aria-hidden="true"` to avoid redundant announcements
- Loading state uses `aria-busy` via `getLoadingProps`

### Keyboard Interaction

| Key | Action |
|-----|--------|
| Tab | Moves focus to the info button (if present), then to the period selector |
| Enter / Space | Activates the info button or opens the period selector |
| Arrow Up / Down | Navigates period selector options when open |
| Escape | Closes the period selector dropdown |
