## Accessibility

- Semantic `<article>` element for self-contained product content
- Heading hierarchy uses `<h3>`, assumes placement below a page `<h2>` category heading
- Title link has `focus-visible` focus ring and is keyboard reachable; `sanitizeHref` strips unsafe protocols
- CTA button has `aria-label` combining the action label and product title for full screen reader context
- `aria-busy="true"` set on root and CTA during loading
- `aria-disabled="true"` set on root when disabled
- Badge overlay marked `aria-hidden="true"` — decorative
- Original price uses `<del>` element for semantic meaning
- Rating rendered via `Rating` atom with accessible radio inputs

### Keyboard Interaction

| Key | Action |
|-----|--------|
| Tab | Moves focus to title link (if href set), then CTA button |
| Enter / Space | Activates focused link or button |
