## Accessibility

- Semantic `<div role="group">` wrapping a native `<input>` (via Input atom)
- `aria-label` recommended when no visible `<label>` is present
- `aria-disabled` set on group when `disabled` or `loading` is true
- `aria-invalid` set on inner input when `error` is true
- `aria-busy` set on inner input when `loading` is true
- `aria-describedby` can be passed through to connect hint or error message elements
- Decorative addon icons include `aria-hidden="true"`
- Focus ring appears on the inner input via `focus-visible:focus-ring-inset`
- Button suffix retains its own accessible name and keyboard behaviour

### Keyboard Interaction

| Key | Action |
|-----|--------|
| Tab | Moves focus to the inner input; addons are not focusable unless they contain interactive elements |
| Tab (with button suffix) | Continues to the Button in the suffix slot |
| Enter / Space | Activates the focused button |
| Standard input keys | Character input, selection, deletion |
